## Root causes (measured)
- Occlusion: menu content (with the Today's machine panel) is taller than the free space above the absolutely-positioned selectors (z-index 50 > overlay 30). On Pixel 7 the cabinet box is only ~358x393, so the Start row sits under #touch-controls; in landscape (915px) the `min-width:769px` rule also hid touch controls on phones.
- Compile storm: NOT texture units (maxTexturesImageUnits=32, only keyLight has a ShadowGenerator). It is UNIFORM BLOCKS: each Babylon light is its own UBO beside Scene/Material/Mesh, and GL_MAX_VERTEX/FRAGMENT_UNIFORM_BLOCKS = 14 on SwiftShader (WebGL2 spec min 12). Nothing in src sets maxSimultaneousLights — Babylon 7.54's glTF loader does: after each glTF load it sets EVERY scene material's maxSimultaneousLights = max(current, scene.lights.length) (node_modules/@babylonjs/loaders glTFLoader, "_loadAsync ... resultPromise"). With 14 → 19 → 26 lights every such material fails to compile; on WebGL2 flippers/pins/bumpers simply didn't render.
