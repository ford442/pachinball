## Objective
Fix invisible/non-moving flipper visuals and ball stuck at launch-lane holographic feeders.

## Current Phase

## Root Causes Found
1. **Flippers invisible:** Tilted `lcdGround` shares the same depth band as flipper meshes (world Y ≈ -0.5 inside ground AABB). Z-fighting hides paddle geometry while Rapier colliders still work.
2. **Ball stuck at launcher:** `quantum-tunnel` input sensor at `(11.5, 0.5, 0)` and `mag-spin` at `(9.25, 0.5, 12)` overlap the plunger lane; feeders capture the ball kinematically before it reaches the main table.
3. **Hologram catch (secondary):** `activateHologramCatch` used local `hologram.position` after bumpers were parented to `playfieldGroup` — wrong world target.

## Fixes Applied
- `object-flippers.ts`: `renderingGroupId = 1`, +0.1 visual Y lift on child meshes
- `material-interactive.ts`: `zOffset = -2` on enhanced flipper PBR
- `config.ts`: moved mag-spin → `(7.5, 15)`, quantum input → `z=14`
- `mag-spin-feeder.ts` / `quantum-tunnel-feeder.ts`: skip capture while `x > 8.5 && z < 10–11` (launch lane)
- `scoring-bridge.ts`: hologram catch uses `getAbsolutePosition()`
- Tests updated for new feeder positions + launch-lane guards
