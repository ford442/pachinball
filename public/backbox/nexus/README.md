# Nexus character pack — NEXUS-7

Per-state character takes for the backbox, routed through
`StateMediaConfig.characterLayer` (poster) and `characterLoop` (optional loop).
Generated by `npm run assets:nexus` (`scripts/generate-nexus-character-pack.mjs`;
puppeteer + ffmpeg/libvpx-vp9). Edit the generator, not the files.

| File | DisplayState | Format |
|------|--------------|--------|
| `idle.png` | IDLE / attract | 1000×600 RGBA poster |
| `idle.webm` | IDLE loop | 800×480 opaque VP9, 2 s seamless |
| `reach.png` | REACH | 1000×600 RGBA poster |
| `fever.png` | FEVER | 1000×600 RGBA poster |
| `jackpot.png` | JACKPOT | 1000×600 RGBA poster |

Rules (checked by `tests/backbox-nexus-pack.test.ts`):

- Posters are 5:3 to match the 20×12 backbox plane and composite with their alpha.
- REACH and FEVER keep the reels visible, so their posters leave the **reel
  window** (x 8–92 %, y 18–70 %) at alpha ≤ 8; art lives in the bottom band and
  side strips. With a poster configured, those states skip their state video.
- A loop in a state that shows reels must be VP9-alpha and verified on WebGPU
  first; only IDLE (reels hidden) ships an opaque loop today.
- Budgets: each PNG ≤ 350 KB, each loop ≤ 500 KB, pack ≤ 2 MB.

Runtime behaviour (`src/display/display-character.ts`, `display-core.ts`):

- The LCD emoji walk-by is suppressed only once a poster has loaded (or the loop
  plays). A missing or failed poster keeps the walk-by and restores the state's
  ordinary image/video.
- The loop plays only without reduced motion, above `QualityTier.LOW`, and not
  in photosensitive FEVER/JACKPOT; otherwise the poster is the static frame.
